# Four-operation typed body subset

The new private payload header and class entries cover create, seal, cancel and withdraw. Public Variant signatures retain original parsing; both paths share the actual native body. Typed calls authenticate the original physical request/context and main RD, borrow fixed POD/spans synchronously and construct no transient Variant containers. Static detail strings avoid a post-effect printable-result allocation.

Create and seal still return the original Unavailable results at their missing admission/record joins. Cancel and withdraw use the original owner transitions. This component does not register external proc names or supply missing original Host/attachment forwarding. A future forwarder must preserve operation/request/generation ownership and validate external pointer spans. Acquire/poll result projection is intentionally absent from this subset.

Independent Sol review found a bounds narrowing issue, corrected before integration: finite/range checks precede the double-to-real_t cast, with exact roundtrip/endpoint checks retained. Astra reconciled that isolated fix. Standalone float/double conversion checks each passed 59 cases; these are not Godot invocation tests.

The actual macOS editor built and linked successfully. The full original-bin suite passed 2,089 cases and 523,709 assertions, zero failures. Existing public/owner regression coverage remains; no direct typed class invocation or successful source admission is claimed. stdout/stderr are preserved, not claimed empty. C11/C++17 header compilation gives identical native sizes and C++ POD checks; clang-format/codespell pass with unchanged source pins.

Exact source, header and evidence hashes are in TYPED_BODY_RECEIPT.json. Local evidence and fixed host are under `work/b4-typed-output-four-20261106/`. Pointer-bearing spans are native ABI, not serialized byte payloads; C must retain actual span backing in its original charged owner. The header subset may unblock those quotes while complete six-operation production support remains open.
