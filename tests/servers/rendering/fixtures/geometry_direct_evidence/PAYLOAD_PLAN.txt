After end assert `driver.payload` contains pipeline ID, index native buffer ID 11, UINT32 format, byte offset = original element offset*4 (fixture index array uses offset=2 => expected bind offset 8), indexed draw count=6, instance=1, first_index=0, and payload order after begin before end. Invalid graph-instance/offset handles remain rejected.
6. This is execution evidence only: it proves original graph/native payload and mapping; it does not prove source identity, native completion, physical retirement, Scene output, or no-next-draw close. Keep those claims separate.
