# Instance192 protected command guard component fixture

Run from the Godot source root:

```sh
python3 tests/servers/rendering/fixtures/particle_external_guard/run.py --mutations
```

Requires `glslangValidator`, `spirv-val`, `spirv-dis` and `clang++` on PATH. Temporary SPIR-V and CPU binaries are removed after the run. No Godot build is launched.

The fixture compiles and validates the production shader's INIT, VALIDATE and FINALIZE variants with 12 bindings and its INIT_EMPTY/FINALIZE_EMPTY variants with only bindings 2–11. Empty variants require no record descriptors or dummy particle allocation. It reflects the 32-byte push constants, 240-byte proof header and 144-byte surface stride, and checks `NoContraction` on validation arithmetic. It extracts the production functions into a scalar C++ harness rather than maintaining a second copy of guard conditions. The harness runs 87 sequential control/interval cases. Additional cases cover distinct indexed/nonindexed surface commands, a second-surface fault zeroing every command, 64/65/129 capacity chunks with padded lanes and poisoned inactive tails, forward/reverse lane and chunk ordering, independent Count and four zero-means-healthy source gates, N=0 gates/count, per-role scalar extents and proven shared READ backing at nonzero offsets. These cases exercise scalar invocation ordering rather than claiming concurrent GPU execution.

Eleven intentional source mutations must fail their independent expectations: truncating initialized/checked surfaces to eight, ignoring each of the four actual gates, ignoring selected count, omitting real Count or CountValidity at N=0, dropping geometric bounds faults, and skipping previous-history validation.

This is component evidence. Scalar lanes do not prove GPU visibility or scheduling. It does not run the E09 source bridge, material shaders, renderer draw consumption, adoption, completion or retirement. The wrapper must record INIT, barrier, every capacity-bounded validation chunk, barrier, FINALIZE, then a barrier before command consumption. Zero capacity selects INIT_EMPTY, a barrier, FINALIZE_EMPTY and the final barrier, with no validation dispatch. It must retain all original backings and immutable proof/material/source associations. Missing chunks are a caller contract failure, not something the shader can infer from a count word.

The shader accepts only Instance192 data. No Indexed144, SceneOnly, double-precision or production qualification capability follows from compiling it. F32 inputs, finite and non-subnormal values, reserved bits, eligibility, history identity, source count equality, metadata, and current/valid-previous bounds are checked. Transform classification, normal/inverse generation, determinant threshold decisions and material displacement recipes still require their original qualified producer and immutable owner proofs; this shader does not independently sign those algorithms.

Binding 3 is SOURCE_COUNT. Bindings 8–11 are CountValidity, AttributesValidity, DenseIdsValidity and InstanceGate respectively. All five are retained real original source buffers, never CPU scalar uploads. `GeometryProof.source_accessor` at byte192 is `[count_word,0,0,space]`; `source_gate_words` at byte208 contains the four corresponding scalar word offsets; `options` moves to224 and the surface table starts at240. Every gate uses fixed fault==0 semantics, with no selectable rule or gate mask. Each scalar must fit its own bound buffer even at N=0. Five readonly source descriptors may share proven original READ backing, including one persistent gate scalar for Initial; they have no `restrict` promise. All other blocks remain exclusive and must not alias any source. The original owner must still authenticate exact accepted uses, subranges, backing generations, READ/READ alias legality and retention multiplicity. A pure layout plan cannot infer those typed-source facts. These private component parameters do not grant E07 publication or production authority.

Scratch words 0–7 capture OutputMeta32 once during INIT. Word 8 is the aggregate atomic fault, word 9 is the minimum failure tuple `instance*16 + previous_domain*8 + surface`, word 10 is immutable INIT fault, and 11–15 are zero. Metadata/source preflight faults use tuple 0 and are distinguished by word 10. Record numeric/layout failures use surface 0. VALIDATE reads only word 10 to skip globally invalid inputs; a record fault never causes another lane to skip and lose its independent fault bits. Status is not observable as completed merely because INIT wrote fault zero.

For isolated candidate validation, `--shader /absolute/candidate/particles_external_guard.glsl --native-source-root /absolute/godot/source` selects candidate shader text with the original owner limit. `--shader-only` performs all five SPIR-V/reflection checks without a CPU executable; `--syntax-only` additionally translates and syntax-checks the CPU harness without executing it. The normal invocation retains its original component execution and `--mutations` behavior. All modes report their limited evidence.
