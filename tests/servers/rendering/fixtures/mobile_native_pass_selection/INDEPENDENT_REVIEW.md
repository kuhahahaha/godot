# Independent Mobile native pass source review

Verdict: no blocking source finding. Three current source hashes exactly match parent PRE_BUILD_SOURCE_IDENTITY.json under work/sprite-mobile-native-pass-selection-20261107. Reviewer changed no source and ran no build/Godot/GPU. Original HEAD shader-version switch and current selector are preserved as source excerpts; SOURCE_MATRIX.json evaluates their actual extracted conditional expressions across576 input rows (480 admitted/96 refused), all equivalent. This is finite source-derived expression equivalence, not compiled helper/runtime execution.

Opaque pass freezes actual opaque framebuffer format before draw_list_begin, subpass0, current mono/multiview and defer_fog. Original draw_list_begin initializes subpass0. Only the existing defer_fog branch switches to subpass1 before sky and merged alpha; SkyRD::draw_sky reads the current pass but does not advance it. Merged alpha accordingly freezes subpass1 for deferred fog, otherwise0, and its original defer_opaque_fog=false remains normal color/lightmap. It is selected only when the same merge/alpha-nonempty condition later consumes it. The sole separate-alpha original pre-begin draw_list_get_current_pass remains, with original framebuffer-format input; no normalization to0 or change to its previous-list semantics is introduced.

Wrapper paths select before begin, including shadows/motion; direct material and UV2 query actual framebuffer/choose before begin. All original _render_list call sites consume the same params.native_pass. Dispatcher uses its pass mode; actual pipeline key uses its version_for_surface(element_info.uses_lightmap), framebuffer and subpass. Motion retains the original always-MOTION_VECTORS_MULTIVIEW version even for mono/default view_count. Shadow supports original >1 multiview; shadow-DP/depth-material reject >1. Counts0/1 keep original mono behavior. Color/lightmap/fog mappings agree in every source matrix row. Invalid selector output is assigned only at final success.

Lightmap remains a per-surface decision between the two frozen pass variants, not a list-wide first-surface choice; noncolor variants deliberately equal each other. RenderElementInfo is initialized together with lod/lightmap bits by original _fill_instance_data. Cull/material/specialization/input-mask/vertex selection/ubershader and pass-specific draw behavior remain in original templates.

UV2 preserves the exact nine offsets, normalization by region size and final zero-offset call. Unlike Clustered, Mobile originally constructs UV2 RenderListParameters with force_wireframe=false and performs no true->false transition; this remains unchanged. The draw still reads p_params->uv_offset and p_params->force_wireframe dynamically rather than freezing them. This avoids incorrectly importing Clustered behavior.

Four new doctest cases invoke the real production helper and version_for_surface through a TESTS_ENABLED private friend: four noncolor modes across view counts0/1/2 and both fog inputs; both color modes across mono/multiview/lightmap/fog variants; opaque/merged/separate-alpha/UV2 framebuffer/subpass hand expectations; invalid mode and unsupported multiview with every output field unchanged. They test selection branches, while actual caller wiring is separately source inspected. tests/SCsub recursive discovery and TEST_FORCE_LINK are present. No external grants, RESERVING contexts, BOUND relaxation, public ABI or owned-prefix/accepted join is added.

Parent has separately reported fresh build and CPU/GPU results in work/sprite-mobile-native-pass-selection-20261107/VALIDATION.json. Those are parent runtime evidence; this independent review does not relabel source enumeration as runtime. No remaining source blocker found for integration.
