Current D chain: `register_types.cpp` → `HostAttachmentInstaller::install_main_storage()` → `OriginalDeviceSessionRef::bind_main_scene_ready()` → `read_storage_owner_inputs()`. The last returns `host.storage_owner_transport / E05 / UNAVAILABLE` before storage commit. `MainRDStorageTransport` consumes create/retire/observe/release from the original binding; `E09NativeRecorder` uses the ticket and original report/facts/copy paths. Source-level presence does not prove successful completion or same-request readback.

The explicit `device_session_qualification_cancel_v1` is registered and looked up in this source revision; cancellation and physical-retirement release remain distinct operations. No default owner, synthetic token, or policy is supplied by this census.
