# CPU to GPU empty point conversion

CPU POINTS and DIRECTED_POINTS with no emission points deactivate every particle. GPU conversion previously kept emission enabled, reset the amount ratio to one, and built no point texture. Both 2D and 3D conversion now set the target amount ratio to zero for an empty point source, and reset it to one on a later populated conversion. The generated ParticleProcessMaterial shader explicitly deactivates a restart when AMOUNT_RATIO is zero, including the random value zero boundary.

The headless scene fixture failed before the conversion change (exit 1 in both dimensions) and passes after it (exit 0). The shader source fixture failed before the shader change and passes after it. A mixed-worktree `scons tests=yes platform=macos target=editor -j4` rebuild passed; binary SHA256 `2c21bbc51d511b8bb2f74f82882cdd611f552d031402c0b6fe01c618f45223e3`. The rebuilt binary passed the empty-point and CPU point-array fixtures, and conversion doctests passed 11 cases / 59 assertions. These checks establish scene state and generated shader source under dummy rendering; live RD and GLES3 emission was not measured. The build includes unrelated concurrent worktree edits.
