# Uniform-set invalidation callback lifetime — 2026-10-30

`RenderingDevice::_free_internal()` formerly destroyed the original RID-owned `UniformSet` and then read its callback and userdata through the ended object lifetime. The fix copies both values before RID destruction and invokes the same callback synchronously afterward. The test-only, thread-local hook deterministically allocates a replacement in the same RID slot after destruction; it is not a production ownership or completion authority.

The public `free_rid()` control failed before the fix (1 case, 3/5 assertions, rc 1: original callback was not called) and passed afterward (1 case, 5/5, rc 0). On the final test-enabled macOS editor, serial Qualification 103/1901, RenderingDevice 13/219, device_exit 133/2619 and K03 44/1153 passed, rc 0. The build returned 0; see manifest for exact source and binary hashes. A prior parallel test run collided on a shared test directory: one process did not execute tests despite rc 0, and device_exit had one failing case. Those logs remain as negative evidence and are not used as the serial results.

A separate old QRT fixture started on Metal 4.0 / Apple M3 Pro but exited with rc 134 after two native-return lines. Source `qrt_ticket_probe.cpp` explicitly calls `_Exit(134)` when either `QB1_CAPTURE_CONTAINER` or `QB1_BODY_CONTAINER` is missing; this invocation omitted both. It did not reach unit or ticket work and is not an engine-crash or GPU-success claim. A debugger attempt was stopped before a backtrace to avoid collision with another work line's shared Godot tests. This source change does not address unchecked descriptor return, all-parent retention, callback synchronization with concurrent unregistration, or finalization; those original obligations remain open. Review is author self-review, not independent review.
