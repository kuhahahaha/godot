Calls require the original retained, live native Object pointer under the original caller's admitted main-thread source window. D checks type/thread/span/capacity/source scalars and native sample output. It does not authenticate that E04 window or defend arbitrary dangling pointers. The original Ref/source-binding/revocation/recipe/window and B reservation remain C/A owner responsibilities. No signal-count, ObjectID lookup, constructor default, completion token or Ready substitute is issued.

Caller storage is used directly. No duplicate payload, script callback or lazy bake. Curve provenance capacity follows the supplied admitted storage, independently of sample count. Malformed metadata/spans (null/misaligned scalar outputs, overlap between output counts/metadata/arrays/input, or address-range overflow) return BAD_ARGUMENT before output writes; such invalid spans cannot represent independent prefix counts and their outputs are not initialized. This exception is analogous to null output pointers and was explicitly independently reviewed. With valid, disjoint typed spans, limits/source/sampling failures retain actual initialized prefixes and available revision. The exact original caller must not consume outputs from malformed argument layouts.
