# Author review

The macOS storage is a function-static original SDK map, matching Wrapped's existing technique. std::map node references remain stable during insertions; lookup/insertion is mutex-protected, and each thread accesses only its own pointer after lookup. Nodes are not erased while callbacks can run. Original callback entry/frozen/reentry checks and reset points are retained verbatim except accessor spelling. The map dies with the image after core permits/holders retire. Non-macOS branch keeps original native TLS. No shared globals replace per-thread values, no grant or second lifecycle registry is created, and sticky guarded_claimant is not reset.

Initial compile exposed class_db.hpp treating the accessor function address as a bool. The final patch migrates this original conditional too and uses -Werror=pointer-bool-conversion. Current native reload, thread isolation and original SDK controls passed after this correction. The original no-schedule negative remains fail-closed. This is a private source candidate with apply-check evidence; it is not a built canonical product or independent review. Current source/test harness consumers beyond the provided production patch still require coordinated spelling migration at intake.
