## Overflow, same-value setters and failures

`_mesh_revision_advance` increments a nonzero original revision; UINT64_MAX transitions to zero once and zero stays zero. `mesh_selection_acquire` rejects zero with ERR_PARAMETER_RANGE_ERROR before incrementing hold count. It snapshots current revision into the existing private lease generation field. Release checks the original RID, live hold count and exact nonzero revision, then clears the lease snapshot. No new heap state, global IDs, registry or allocation counters.

Successful same-value setter/clear calls can advance conservatively; this is a state invalidation token, not exact semantic edit count. Rejected validation/hold operations do not bump. Region APIs are special: current code changes static metadata before RD buffer_update. RD `_buffer_update` (`servers/rendering/rendering_device.cpp:1207–1370`) can record chunked prefixes before later failure; changing it into success-only tracking would leave old revisions on changed state. Candidate advances at the first existing metadata mutation and preserves original Error behavior rather than inventing transactional GPU success.

A selected original lease prevents all direct tracked mutations. Indirect shadow actual mutation cannot target a correctly selected mesh because selection rejects a valid shadow relation; stale null reverse entries skip no-op mutation but preserve original notifications. Cache-only changes remain allowed only where they do not affect source state. This does not freeze the internals of assigned materials or externally owned buffers; selected ordinary meshes already exclude external/skin/instanced sources, and MaterialStorage selection remains required separately.

## Review corrections

Independent review found original add_surface could set has_bone_weights at original cpp:494 then reject zero vertex/index counts at cpp:519, before the candidate publication increment. Revised candidate rejects that exact condition before temporary Surface allocation and moves the bone flag assignment to surface publication, so no rejected owner prefix or leaked temporary Surface remains on this branch. Regression compares actual mesh_needs_instance with skeleton=true, owner bone flag, surface directory, native buffer allocation count, and unchanged revision. The prior helper also skipped stale-null notifications; revised helper retains changed_notify unconditionally and the regression counts original DependencyTracker callbacks while preserving selected revision/release.
