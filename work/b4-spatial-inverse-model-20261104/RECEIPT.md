# Spatial inverse model component

The current output contract requires `INV_MODEL_MATRIX` before spatial vertex and fragment author code. The frozen a2 System host does not recognize this identifier; the actual Metal/Mobile shader compilation in `baseline.log` is the target red. A preliminary script-parser error (`RenderingServer.sync` is not exposed) was corrected before recording that baseline. Process success alone is not shader success: the expected unknown-identifier diagnostic is checked explicitly.

Spatial vertex and fragment now register a readonly MAT4 builtin. The scene RD compiler/shader implementation supplies the packet inverse for Instance192 and native model inverse otherwise; that implementation has its own shader fixture and receipt. GLES3 maps the same builtin to `inverse(model_matrix)` in its spatial compiler, without enabling External output. Canvas and light stage gain no builtin. Native shaders which do not use this identifier need no added inverse evaluation.

Two new force-linked engine tests check V/F registration and compilation, assignment rejection in each stage, and Canvas rejection. They have NOT run. ShaderTypes plus the test TU and GLES3 material storage syntax checks returned 0, using unchanged frozen full-tree includes/generated headers. The first GLES3 syntax attempt lacked thirdparty/glad includes; adding the actual dependency include closed it. No B4 engine build or current GPU run occurred. The previous matched System host is untouched. This is a source/syntax component, not N17 transform, mirror, material, source, full B4 or cross-platform qualification.

Separate Sol source/GLES template review found no blocking interface defect (`../b4-spatial-inverse-model-review-20261104/REVIEW.md`), and Astra reviewed the combined RD source/template component (`../b4-instance192-independent-review-20261104/REVIEW.md`). The latter found a global-group Native trails isolation defect, fixed and re-reviewed before this package was staged. These reviews do not turn the unrun engine tests into passes.
