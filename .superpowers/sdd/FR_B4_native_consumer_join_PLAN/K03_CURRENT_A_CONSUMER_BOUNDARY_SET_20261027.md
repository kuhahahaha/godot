shared ANGE worktree. Each receipt has its own source snapshot, manifest, raw
logs, and independent review. The set advances independent work while keeping
E20/owner/native/GPU/Ready authority separate.

## Boundary

allocation, U03/U04/R01/C02/C06/E09 association, native capture, GPU output,
PCK, Ready, Verified, or physical disposal. It contains no fallback owner,
synthetic token, or qualification promotion.
