## 0. Decisions

1. **Zero-Growth `784B` `PrepareV1` C ABI (`Recipe 3` & `413` Gate Mask)**:
   - In [gdextension_interface.json](../core/extension/gdextension_interface.json:13043), append `GDEXTENSION_MATERIAL_QUALIFICATION_RECIPE_CURRENT_RESET_F32_WORLD_PARTICLE_WPO_V1 = 3` and `GDEXTENSION_MATERIAL_QUALIFICATION_PARTICLE_WPO_SOURCE_GATE_ALLOWED_MASK_V1 = 413` (`0x0000019du = 412u | 1u`), matching `FR_particle_wpo_bounded_displacement_PLAN.md` §0.2.
   - Preserve `sizeof(GDExtensionMaterialQualificationPrepareV1) == 784` ([gdextension_production_material_qualification.cpp](../core/extension/gdextension_production_material_qualification.cpp:54)): enforce `prepare->reserved == 0` when `prepare->recipe != 3` (preserving [test_material_qualification_action7.h](../tests/servers/rendering/test_material_qualification_action7.h:324)), and decode `prepare->reserved` (`bytes 780..783`) as IEEE-754 F32 `max_vertex_offset` $R$ when `prepare->recipe == 3`, requiring normal finite F32 in `(0.0f, 16.0f]` (`0x00800000u <= bits <= 0x41800000u`, else `ERR_INVALID_DATA`, reason `3`).
   - Define `constexpr bool mq_is_particle_color_recipe_v1(uint32_t p_recipe)` (`p_recipe == 2u || p_recipe == 3u`) at [gdextension_production_material_qualification.cpp](../core/extension/gdextension_production_material_qualification.cpp:191) and use it at **all three** color-oracle sites: `prepare` (`:877`), **`record` (`:1414`, ensuring alpha clears to `0.0f` and readback copies `32x16` `R16G16B16A16_SFLOAT` rather than `D32_SFLOAT`)**, and `read` (`:1666`).
2. **Scaled `s = 0.4375f / (0.5f + R)` `32x16` `R16G16B16A16_SFLOAT` Oracle with Wide Z `[0.0625f, 64.0f]` & Exact 48-Word `fixed_instance192(s)` (Cross-Repo Lock with ANGE `A6`)**:
   - Scaling `fixed_instance192` by `const float s = 0.4375f / (0.5f + R); const float inv_s = 1.0f / s;` maps legal `[-(0.5 + R), +(0.5 + R)]^2 x [-R, +R]` to **$[-0.4375, +0.4375]^2 \times [-2.0 - sR, -2.0 + sR]$** — keeping the **exact 384-pixel `exterior_mask`** (`cols 0..7, 24..31`, `rows 0..3, 12..15`) active for **all** $R \in (0.0, 16.0]$.
   - **Wide Z Frustum**: `fixed_camera_desc = { 2.0f, 0.0625f, 64.0f, 0.0f, 0.0f, 0.0f, 32.0f, 16.0f }` (`z_near = 0.0625f, z_far = 64.0f` in [render_scene_data_rd.cpp](../servers/rendering/renderer_rd/storage_rd/render_scene_data_rd.cpp:335)) prevents diagonal XY+Z escapes (e.g. `VERTEX += vec3(0.6, 0.0, 1.3)` or `vec3(2.0, 0.0, 2.0)`) from near/far-clipping out before hitting the 384 exterior pixels.
   - **Exact 48-Word `fixed_instance192(s)` Non-Zero Layout**:
     - `words[0] = words[5] = words[10] = float_bits(s)`, `words[11] = float_bits(-2.0f)`
     - `words[12] = words[17] = words[22] = float_bits(1.0f)`
     - `words[24] = words[29] = words[34] = float_bits(inv_s)`, `words[35] = float_bits(2.0f * inv_s)`
     - `words[36] = words[37] = words[38] = words[39] = float_bits(1.0f)`, `words[46] = 0u` (`Recipe2FlagsWord == 0u`), all other words `0u`.
   - **Honest `all_finite && exterior_zero` Verifier**: Verifies `all_finite && exterior_zero` over the `1024` `R16G16B16A16_SFLOAT` readback words (`interior_nonzero` is NOT checked so valid `ALPHA = sin(TIME)` shaders rendering `0.0` at `TIME = 0.0` pass; pure axial Z displacement without XY extent is bounded at runtime by `SurfaceProof` `[-R_s, +R_s]^3` + `ParticlesExternalGuard` `BOUNDS_FAULT`).
   - `mq->oracle.recipe` hashes `"godot.material_qualification.recipe.current_reset_f32_world_particle_wpo.v1"` over `132` bytes (`vec_bytes[96] + verifier[32] + max_vertex_offset_bits_le[4]`).
3. **`wpo_output_pass_mask` Eligibility (`output_pass_mask == 0` Until WPO-Qualified; `MOTION_VECTORS` Rejected)**:
   - In `SceneShaderForwardClustered::ShaderData::get_native_instance192_shader_features` ([scene_shader_forward_clustered.cpp](../servers/rendering/renderer_rd/forward_clustered/scene_shader_forward_clustered.cpp:289)) and `SceneShaderForwardMobile::ShaderData::get_native_instance192_shader_features` ([scene_shader_forward_mobile.cpp](../servers/rendering/renderer_rd/forward_mobile/scene_shader_forward_mobile.cpp:304)): when `!features.zero_displacement`, set `features.output_pass_mask = 0u` and compute `features.wpo_output_pass_mask = (instance192_shader_supported() && (features.material_recipe_rejections & ~413u) == 0u) ? (transparent ? Output::PASS_TRANSPARENT : (Output::PASS_OPAQUE | Output::PASS_DEPTH)) : 0u` (omitting `PASS_SHADOW | PASS_PROBE`).
   - In `MaterialStorage::material_selection_get_shader_observation` ([material_storage.cpp](../servers/rendering/renderer_rd/storage_rd/material_storage.cpp:1232)): when `!features.compiled.zero_displacement`, expose `observation.output_pass_mask = wpo_qualified_for_lease ? features.compiled.wpo_output_pass_mask : 0u`. In `ExternalOutputOwner::acquire_generation_selection` ([external_output_owner.cpp](../servers/rendering/renderer_rd/storage_rd/external_output_owner.cpp:2122)) and `select_preparation_tuple` (`:598`), enforce `(config.pass_mask & ~obs.output_pass_mask) == 0` and reject `config.motion == ExternalOutputConfig::REQUIRED` (`ExternalPacketPass::MOTION` / `MOTION_VECTORS`) whenever `!obs.zero_displacement` (`ERR_UNAVAILABLE`).
4. **Frozen `ExternalOutputOwner::GenerationMaterialSelection::wpo_max_offset_m` & Per-Surface `SurfaceProof` `[-R_s, +R_s]^3`**:
   - In `Registry::production_read_material_qualification` ([gdextension_production_material_qualification.cpp](../core/extension/gdextension_production_material_qualification.cpp:1600)), verify `all_finite && exterior_zero` before stamping `materials->material_record_qualified_wpo(material_rid, material_generation, R)`.
   - **Immutable Per-Owner Freeze**: During `ExternalOutputOwner::acquire_generation_selection` ([external_output_owner.cpp](../servers/rendering/renderer_rd/storage_rd/external_output_owner.cpp:2122)), snapshot `float wpo_max_offset_m = obs.qualified_wpo_max_offset_m;` into `ExternalOutputOwner::GenerationMaterialSelection` ([external_output_owner.h](../servers/rendering/renderer_rd/storage_rd/external_output_owner.h:267)) under the held `NativeSelectionLease`, and return that frozen value via `BoundMaterialContact::wpo_max_offset_m` (`:2170`). Thus if Emitter A (`R_A = 2.0f`) and Emitter B (`R_B = 0.5f`) share one `Material` RID, re-qualifying for B never alters A's `SurfaceProof` (`particles_storage_external.cpp:349` `memcmp` invariant preserved!).
   - In `ParticlesStorage::_external_guard_prepare_owned_prefix` ([particles_storage_external.cpp](../servers/rendering/renderer_rd/storage_rd/particles_storage_external.cpp:333)), require `contact.material.zero_displacement || (contact.wpo_max_offset_m > 0.0f && contact.wpo_max_offset_m <= 16.0f && (contact.material.material_recipe_rejections & ~413u) == 0u)`, and set `surface_proof.current_displacement_min/max = {-R_s/+R_s}` (and `previous_displacement_min/max` when `!p_history`), keeping `INDEXED_144` (`:576`) strictly `zero_displacement == true`.
