## 0. Decisions

1. **Scope, Exact Zero-Basis Guard Rule (`WORLD`), & `LOCAL`-Space `Host^-1` Margin**:
   - Refine `affine_interval` in [particles_external_guard.glsl](../servers/rendering/renderer_rd/shaders/particles_external_guard.glsl:218) so that when all three linear basis lanes of `row` are IEEE-754 zero (`(floatBitsToUint(row.x) & 0x7fffffffu) == 0u && (floatBitsToUint(row.y) & 0x7fffffffu) == 0u && (floatBitsToUint(row.z) & 0x7fffffffu) == 0u`), after checking `isnan`/`isinf` on `x`, `y`, `z`, and `row.w` (`numeric_valid`), `affine_interval` returns `vec2(row.w, row.w)` without adding `ROUNDING_FLOOR` (`2^-20`) zero-product noise.
   - **Why `LOCAL` space (`proof.source_accessor.w == 2u`) still requires `>= 1.0e-4f` declaration AABB padding**: at [particles_external_guard.glsl](../servers/rendering/renderer_rd/shaders/particles_external_guard.glsl:307), `world_x/y/z = [tx, tx]` is transformed back into emitter-local space via `affine_interval(inverse0..2, world_x, world_y, world_z, numeric_valid)`. Because `Host^-1` (`inverse0..2`) has a non-zero rotated/scaled basis, `affine_interval` widens the local interval by `~6 * 2^-20` (`~5.72e-6f`) on top of F32 `Host * local -> world` roundtrip error. `FR_particle_rnd_sprite_ribbon_zero_size.md` locks an outward `>= 1.0e-4f` pad on `LOCAL` `current_decl_min/max` in ANGE, and `T01` verifies both the `1e-4f`-padded `PASS` and unpadded boundary `BOUNDS_FAULT = 64u` under rotated+translated `Host^-1`!
   - Why we do **not** add an `M * M_inv == I` check inside `particles_external_guard.glsl`: existing guard contract ([README.md](../tests/servers/rendering/fixtures/particle_external_guard/README.md:17)) and tests ([harness.cpp.in](../tests/servers/rendering/fixtures/particle_external_guard/harness.cpp.in:174) shear/mirror cases, plus [test_external_native_output_e2e.h](../tests/servers/rendering/test_external_native_output_e2e.h:223) `flags = 1u` with zero `inv_model`) delegate inverse-matrix synthesis to the qualified producer while the guard proves F32 finiteness, non-subnormal encoding, reserved bits, history identity, and world/declaration bounds containment.
2. **C++ Checked Producer / Reference Builders & Fail-Closed `NaN`/`Inf` Order**:
   - `ParticlesMeshLightSortRD::flush_subnormal_and_neg_zero(float p_value, float &r_out)`: returns `false` if `!Math::is_finite(p_value)` (`(bits & 0x7f800000u) == 0x7f800000u`); flushes `(bits & 0x7f800000u) == 0u` (subnormals and `-0.0f`) to `+0.0f` (`0x00000000u`); otherwise outputs `p_value` unchanged.
   - `ParticlesMeshLightSortRD::make_canonical_degenerate_instance192(...)`: writes zero `transform_rows` basis + flushed `(tx, ty, tz)`, unit identity `normal_row0..2`, exact translation inverse `{1,0,0,-tx; 0,1,0,-ty; 0,0,1,-tz}`, zero `color`, flushed `custom0 = p_uv_rect`, `particle_id`, `flags = 17u | (p_has_previous ? 2u : 0u)`, `reserved_zero = 0u`.
   - `ParticlesMeshLightSortRD::build_instance192_record_checked(...)`: returns `ERR_INVALID_PARAMETER` on `NaN`/`Inf`; emits `make_canonical_degenerate_instance192` when $\min(l_0, l_1, l_2) \le 10^{-6}$ and `p_allow_zero_scale_degenerate == true` (else `ERR_INVALID_PARAMETER`); **always** returns `ERR_INVALID_PARAMETER` when $\min(l_0, l_1, l_2) > 10^{-6}$ yet $|\det(\text{basis})| \le 10^{-12} \cdot (l_0 l_1 l_2)$ (collinear/coplanar non-zero singular matrix).
   - **Fail-Closed `NaN`/`Inf` Pre-Check in `ParticlesRibbonRD`**: in both `build_ribbon_segment_quad` ([particles_ribbon_rd.cpp](../servers/rendering/renderer_rd/storage_rd/particles_ribbon_rd.cpp:168)) and `build_ribbon_segment_quad_checked`, check `!Math::is_finite(p_half_width) || !p_head_world.is_finite() || !p_tail_world.is_finite() || !p_camera_world.is_finite()` **FIRST** (zeroing output vertices/indices fail-closed and returning `ERR_INVALID_PARAMETER` in `build_ribbon_segment_quad_checked`) **BEFORE** admitting finite `p_half_width <= 0.0f` or `||tail - head|| <= 1e-6f` as degenerate `[P0, P0, P1, P1]` with `pad0 = 0u` (`word[3]`) and `pad1 = 0u` (`word[7]`).
3. **Cross-Repo Wire Lock for `RibbonSegmentEndpointKey32` (`endpoint_key_words[6]` / `Float144Vertex` `word[34]`)**:
   - Align `RibbonSegmentEndpointKey32` ([particles_ribbon_rd.h](../servers/rendering/renderer_rd/storage_rd/particles_ribbon_rd.h:47)) and `Float144Vertex::set_endpoint_key` / `get_endpoint_key` ([particles_ribbon_rd.cpp](../servers/rendering/renderer_rd/storage_rd/particles_ribbon_rd.cpp:43)) to ANGE's exact 8-word (`32B`) wire layout (`ribbon_frame_history.cpp:41-50`):
     - `words[0..1]` (`Float144Vertex` `words[28..29]`): `start_id_index`, `start_id_tag`
     - `words[2..3]` (`Float144Vertex` `words[30..31]`): `end_id_index`, `end_id_tag`
     - `words[4..5]` (`Float144Vertex` `words[32..33]`): `group_lo`, `group_hi`
     - `word[6]` (`Float144Vertex` **`word[34]`**): **`subsegment_index`** (`0..3` for `tessellation_factor: 1..4`)
     - `word[7]` (`Float144Vertex` **`word[35]`**): **`valid_mask`** (`1u` when populated, `0u` for unpopulated/empty key)
   - Provide `RibbonSegmentEndpointKey32::from_legacy_ids(uint64_t p_emitter_id, uint64_t p_trail_id, uint64_t p_head_id, uint64_t p_tail_id, uint32_t p_subsegment = 0u)` (mapping `head_id -> start_id`, `tail_id -> end_id`, `emitter_id ^ (trail_id << 1) -> group`, `subsegment_index = p_subsegment & 3u`, `valid_mask = (p_emitter_id || p_trail_id || p_head_id || p_tail_id) ? 1u : 0u`) and update existing call sites in [test_particle_ribbon_rd.h](../tests/servers/rendering/test_particle_ribbon_rd.h:123), plus `with_subsegment(uint32_t p_sub)` (`copy.subsegment_index = p_sub & 3u; copy.valid_mask = 1u;`) and `get_subsegment() const` (`return subsegment_index;`). Zero change to `particles_external_guard_indexed144.glsl` because `words[28..35]` already compares all 8 `u32` words bit-for-bit.
4. **Thread & Resource Authority**:
   - All new C++ helpers are pure stateless value functions; no new RD allocations, mutexes, or render-thread dispatch rules are introduced. `ParticlesExternalGuard` and `ParticlesExternalGuardIndexed144` retain main-render-thread pipeline ownership ([particles_external_guard.cpp](../servers/rendering/renderer_rd/effects/particles_external_guard.cpp:38)).

## Implementation

### Phase 1: `particles_external_guard.glsl` Zero-Basis Exact Affine Interval & `LOCAL` Margin Vectors
1. In [particles_external_guard.glsl](../servers/rendering/renderer_rd/shaders/particles_external_guard.glsl:218), update `affine_interval(vec4 row, vec2 x, vec2 y, vec2 z, inout bool numeric_valid)`:
   - Validate `any(isnan(x)) || any(isinf(x)) || any(isnan(y)) || any(isinf(y)) || any(isnan(z)) || any(isinf(z)) || isnan(row.w) || isinf(row.w)` -> set `numeric_valid = false; return vec2(0.0);`.
   - Check `bool zero_basis = (floatBitsToUint(row.x) & 0x7fffffffu) == 0u && (floatBitsToUint(row.y) & 0x7fffffffu) == 0u && (floatBitsToUint(row.z) & 0x7fffffffu) == 0u;`.
   - When `zero_basis` is true, return `vec2(row.w, row.w)` (exact collapsed world translation in IEEE-754); otherwise execute the existing `multiply_interval` + `add_interval` chain unchanged.
2. Extend [harness.cpp.in](../tests/servers/rendering/fixtures/particle_external_guard/harness.cpp.in:231) with CPU guard cases covering:
   - `WORLD` (`source_accessor.w == 1u`) canonical zero-area `Instance192Record` seated at exact lower bound `ty == current_decl_min.y == cull_min.y == -1.0f` (`flags = 17u` and `19u` with matching `previous_records` ID) -> `expect(0, 1, ...)`.
   - `LOCAL` (`source_accessor.w == 2u`) canonical zero-area `Instance192Record` under translated + $35^\circ$-rotated `Host` / `Host^-1` seated on local floor `local_p = (0.25f, -1.0f, 0.5f)` (`world_t = Host * local_p`):
     - With ANGE's `1.0e-4f` outward-padded `current_decl_min = (-1.0001f, -1.0001f, -1.0001f)` -> `expect(0, 1, ...)` (`PASS`).
     - With unpadded exact `current_decl_min.y = -1.0f` -> `expect(64, 0, ...)` (`BOUNDS_FAULT`, proving why the `>= 1.0e-4f` `LOCAL` pad is mandatory).
   - `WORLD` zero-area `Instance192Record` seated outside `cull_min` (`ty = -1.001f`) -> `expect(64, 0, ...)` (`BOUNDS_FAULT`).
3. **Success check**: `python3 tests/servers/rendering/fixtures/particle_external_guard/run.py` exits `0` with all existing shear/mirror/chunk cases plus new `WORLD` and `LOCAL` zero-area degenerate cases passing, and SCons regenerates `particles_external_guard.glsl.gen.h` cleanly.
