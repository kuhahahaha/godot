## 0. Decisions

1. **Unified `SceneDepthSnapshotMeta256` (`version = 2u`), `Projection::inverse()`, & Viewport Diagnostic Defaults**:
   - Define `struct alignas(16) SceneDepthSnapshotMeta256` in [particles_collision_scene_rd.h](../servers/rendering/renderer_rd/storage_rd/particles_collision_scene_rd.h:111) with `magic = 0x4b303644u` (`"K06D"`), `version = 2u`, and `static_assert`s on `sizeof == 256` and exact byte offsets (`32`, `96`, `160`, `224`, `228`, `232`, `236`, `240`).
   - Matrix & frustum guards: compute `Projection view_from_world(p_cam_transform.affine_inverse())`, `world_to_clip = p_cam_projection * view_from_world`, and **`clip_to_world = Projection(p_cam_transform) * p_cam_projection.inverse()`** (full 4x4 projective inverse via `Projection::inverse()`, **never** `affine_inverse()`!). If `!Math::is_finite(z_near) || !Math::is_finite(z_far) || z_near <= 0.0f || z_far <= z_near` (including orthographic cameras with `z_near <= 0.0f`) or any matrix word is non-finite, clear `FLAG_PRESENT` (`flags = FLAG_REVERSE_Z = 2u`).
   - `words 57..58` (`slab_thickness_m`, `silhouette_jump_m`) hold viewport diagnostic defaults (`0.50f`), while per-emitter `.vfx` overrides pass through ANGE `C05` uniforms so multiple emitters in one viewport never overwrite each other.
2. **GDExtension C ABI Bridge (`core/extension/` <-> `libange`) &Descriptor Lock**:
   - **Cross-Repo Texture/Descriptor Lock**: `depth_texture` is `RD::DATA_FORMAT_R32_SFLOAT` (`TEXTURE_TYPE_2D`, `TEXTURE_SAMPLES_1`, `SAMPLING_BIT | COLOR_ATTACHMENT_BIT | STORAGE_BIT | CAN_COPY_FROM_BIT | CAN_COPY_TO_BIT`), bound on Set 1 as **`RD::UNIFORM_TYPE_TEXTURE`** (`1` RID, sampled in GLSL 450 via `GL_EXT_samplerless_texture_functions` + `uniform texture2D` + `texelFetch`).
   - Expose two C ABI entrypoints in [gdextension_interface.json](../core/extension/gdextension_interface.json:25860) and [gdextension_production_interface.cpp](../core/extension/gdextension_production_interface.cpp:162) (implemented via `Registry` in [gdextension_library_exit_guard.h](../core/extension/gdextension_library_exit_guard.h:1483) and [gdextension_scene_late_depth.cpp](../core/extension/gdextension_scene_late_depth.cpp:134)):
     1. `device_session_scene_depth_snapshot_arm_v1(attachment, input)`: validates `attachment` (`SCENE_PHASE_BEFORE_PARTICLES` on main RD) and calls `ParticlesCollisionSceneRD::request_viewport_depth_snapshot(RID::from_uint64(input->viewport_rid))` so Frame 0's opaque pass already captures.
     2. `device_session_scene_depth_snapshot_borrow_v1(context, request, action_ordinal, viewport_rid, key, out)`: inside `SCENE_PHASE_BEFORE_PARTICLES` physical execution on main RD, calls `ParticlesCollisionSceneRD::acquire_depth_snapshot_read_lease`, binds `Ref<DepthReadLease>` (`public SceneReadContent`) into `request->actions[action_ordinal].scene_attempt.content` via `Registry::scene_phase_borrow` ([gdextension_production_window.cpp](../core/extension/gdextension_production_window.cpp:1489)), and writes `{outcome, sample_token, meta_ssbo_rid, depth_texture_rid, snapshot_generation, width, height, flags}` to `*out`. When the GPU submission finishes or the request retires/cancels, `scene_attempt.content->return_after_reads()` fires automatically!
3. **MSAA 4x Resolve (Forward+), Non-Merged TBDR Pass (Mobile), & Point-Sampled Depth Copy (`p_bilinear_filtering = false`)**:
   - At **both** [render_forward_clustered.cpp](../servers/rendering/renderer_rd/forward_clustered/render_forward_clustered.cpp:2733) and [render_forward_mobile.cpp](../servers/rendering/renderer_rd/forward_mobile/render_forward_mobile.cpp:1107), OR-in `collision_scene_rd->has_pending_depth_snapshot_request(scene_viewport, frame_number)` to set `scene_state.used_depth_texture = true`:
     - Solves **Forward+ MSAA 2x/4x/8x**: activates `resolve_effects->resolve_depth` at `:2752-2756` and `_render_buffers_copy_depth_texture` (`RB_TEX_BACK_DEPTH` `R32_SFLOAT`) at `:2814` before `:2841`.
     - Solves **Forward Mobile TBDR & Opaque-Only Frame 0**: sets `merge_transparent_pass = false; using_subpass_post_process = false; resolve_depth_buffer = true;` at `:1111-1128`, preserving MSAA/opaque depth and routing every demanded frame (even with `0` alpha elements!) through `:1509` and `:1513` strictly pre-transparent (plus a defensive fallback hook at `:1464`).
   - **Point-Sampled Nearest Copy & `D32_SFLOAT_S8_UINT` Slice**: copy into `dst_gen->framebuffer_rid` using `copy_effects->copy_to_fb_rect(src_depth_view, dst_gen->framebuffer_rid, Rect2i(0, 0, w, h), false, false, false, false, RID(), false, false, /*p_linear=*/false, false, Rect2(), 1.0f, /*p_bilinear_filtering=*/false)` ([copy_effects.h](../servers/rendering/renderer_rd/effects/copy_effects.h:373), [copy_effects.cpp](../servers/rendering/renderer_rd/effects/copy_effects.cpp:652) `FILTER_NEAREST`!). If `src_depth` is not `RB_TEX_BACK_DEPTH` (`R32_SFLOAT`) and has stencil (`D32_SFLOAT_S8_UINT` / `D24_UNORM_S8_UINT`), create/cache a depth-only slice view (`RD::TEXTURE_SLICE_DEPTH`).
4. **`RefCounted` `DepthSnapshotGeneration` Lifecycle, Free Order, & Viewport Eviction**:
   - `DepthSnapshotGeneration` (`public RefCounted`) holds `SafeNumeric<uint32_t> active_leases{ 0 }`, `RID meta_buffer`, `RID depth_texture`, and owned `RID framebuffer_rid` (`RD::framebuffer_create({ depth_texture })`). `DepthReadLease` holds `Ref<DepthSnapshotGeneration>`, eliminating any raw-pointer UAF across COW swaps or `retired_depth_snapshots` growth.
   - `release_gpu_resources()` frees `framebuffer_rid` **first**, then `depth_texture`, then `meta_buffer` (and transactionally rolls back `depth_texture` + `meta_buffer` if `framebuffer_create` fails).
   - `RenderSceneBuffersRD::cleanup()` ([render_scene_buffers_rd.cpp](../servers/rendering/renderer_rd/storage_rd/render_scene_buffers_rd.cpp:134)) calls `invalidate_viewport_depth_snapshot(viewport)`, moving any `active_leases.get() > 0` generation to `retired_depth_snapshots` (reaped once `active_leases.get() == 0`) and erasing `depth_snapshots_by_viewport[vp_id]`.

## Implementation

### Phase 1: `SceneDepthSnapshotMeta256` (`v2`), `Projection::inverse()`, & 3-Tap Collision Reference
1. In [particles_collision_scene_rd.h](../servers/rendering/renderer_rd/storage_rd/particles_collision_scene_rd.h:111), define `SceneDepthSnapshotMeta256` (`magic = 0x4b303644u`, `version = 2u`, `FLAG_PRESENT = 1u`, `FLAG_REVERSE_Z = 2u`, diagnostic defaults `slab_thickness_m = 0.50f`, `silhouette_jump_m = 0.50f`) with `static_assert`s on `sizeof == 256` and exact byte offsets (`32`, `96`, `160`, `224`, `228`, `232`, `236`, `240`).
2. Implement `ParticlesCollisionSceneRD::fill_depth_snapshot_matrices(const Transform3D &p_cam_transform, const Projection &p_cam_projection, float p_z_near, float p_z_far, SceneDepthSnapshotMeta256 &r_meta)` using `p_cam_projection.inverse()` (never `affine_inverse()`) and clearing `FLAG_PRESENT` (`flags = 2u`) whenever `!Math::is_finite(p_z_near) || !Math::is_finite(p_z_far) || p_z_near <= 0.0f || p_z_far <= p_z_near` or any matrix element is non-finite.
3. Implement `ParticlesCollisionSceneRD::evaluate_depth_snapshot_v2_collision(...)` in [particles_collision_scene_rd.cpp](../servers/rendering/renderer_rd/storage_rd/particles_collision_scene_rd.cpp:590) matching the 9-step 3-tap Reverse-Z reconstruction, `slab_thickness_m` penetration gate, and `silhouette_jump_m` eye-normal fallback in `FR_particle_par_e10_and_scene_depth.md`.
4. **Success check**: `[particle_scene_k06]` doctests verify all `offsetof`/`sizeof` invariants, `Projection::inverse()` perspective & asymmetric frustum unprojection, ortho `z_near <= 0.0f -> flags = 2u` guard, Frame-0 no-op, sky skip, slab pass-through, and silhouette fallback.

### Phase 2: `RefCounted` `DepthSnapshotGeneration`, `DepthReadLease`, & `core/extension/` C ABI Bridge
1. In [particles_collision_scene_rd.h](../servers/rendering/renderer_rd/storage_rd/particles_collision_scene_rd.h:184) and [particles_collision_scene_rd.cpp](../servers/rendering/renderer_rd/storage_rd/particles_collision_scene_rd.cpp:153):
   - Implement `DepthSnapshotGeneration : public RefCounted` (`SafeNumeric<uint32_t> active_leases{ 0 }`, `RID meta_buffer`, `RID depth_texture` `RD::DATA_FORMAT_R32_SFLOAT`, `RID framebuffer_rid`):
     - Transactional allocation: create `meta_buffer` (`256B`), then `depth_texture`, then `framebuffer_rid = rd->framebuffer_create({ depth_texture })`; if any step fails, immediately free prior RIDs and return `ERR_CANT_CREATE`.
     - `release_gpu_resources()`: free `framebuffer_rid` **first**, then `depth_texture`, then `meta_buffer`, decrementing `live_rid_counter` per freed RID.
   - Implement `DepthReadLease : public GDExtensionDeviceExit::SceneReadContent` holding `Ref<DepthSnapshotGeneration>` (`active_leases.increment()` / `decrement()` + `ParticlesCollisionSceneRD::active_lease_counter`), `request_viewport_depth_snapshot`, `has_pending_depth_snapshot_request(RID p_viewport, uint64_t p_frame_number)`, `acquire_depth_snapshot_read_lease`, `invalidate_viewport_depth_snapshot(RID p_viewport)` (moving leased generations into `retired_depth_snapshots` and erasing `depth_snapshots_by_viewport[vp_id]`), and `reap_retired_depth_snapshots_locked()`.
2. In [gdextension_interface.json](../core/extension/gdextension_interface.json:25860), [gdextension_production_interface.cpp](../core/extension/gdextension_production_interface.cpp:162), [gdextension_library_exit_guard.h](../core/extension/gdextension_library_exit_guard.h:1483), and [gdextension_scene_late_depth.h](../core/extension/gdextension_scene_late_depth.h:82) / [gdextension_scene_late_depth.cpp](../core/extension/gdextension_scene_late_depth.cpp:134):
   - Add `GDExtensionSceneDepthSnapshotArmV1`, `GDExtensionSceneDepthSnapshotBorrowResultV1`, `device_session_scene_depth_snapshot_arm_v1`, and `device_session_scene_depth_snapshot_borrow_v1` (delegating retention and GPU-completion `return_after_reads()` to `Registry::scene_phase_borrow` for `SCENE_PHASE_BEFORE_PARTICLES`).
3. **Success check**: `[particle_scene_k06]` tests verify `RefCounted` COW split under active lease, resize-while-leased + `retired_depth_snapshots` reap without UAF, closed-viewport eviction, transactional rollback, and live `device_session_scene_depth_snapshot_{arm,borrow}_v1` lease borrow + auto-return (`live_rid_count == 0` at `shutdown()`).

### Phase 3: Forward+ MSAA & Mobile Non-Merged `used_depth_texture` Gate + Point-Sampled Capture
1. In **both** [render_forward_clustered.cpp](../servers/rendering/renderer_rd/forward_clustered/render_forward_clustered.cpp:2733) and [render_forward_mobile.cpp](../servers/rendering/renderer_rd/forward_mobile/render_forward_mobile.cpp:1107), update the pre-resolve depth demand check to:
   - `if (GDExtensionDeviceExit::has_active_late_transparent_depth_phase(RD::get_singleton(), scene_viewport) || (ParticlesStorage::get_singleton() && ParticlesStorage::get_singleton()->get_collision_scene_rd() && ParticlesStorage::get_singleton()->get_collision_scene_rd()->has_pending_depth_snapshot_request(scene_viewport, frame_number))) { scene_state.used_depth_texture = true; }`
   - Also invoke `dispatch_late_particle_collision_phase` after `draw_list_end()` in [render_forward_mobile.cpp](../servers/rendering/renderer_rd/forward_mobile/render_forward_mobile.cpp:1464) as a defensive guard if `merge_transparent_pass` was forced externally.
2. In `RendererSceneRenderRD::dispatch_late_particle_collision_phase` ([renderer_scene_render_rd.h](../servers/rendering/renderer_rd/renderer_scene_render_rd.h:384), [renderer_scene_render_rd.cpp](../servers/rendering/renderer_rd/renderer_scene_render_rd.cpp:2066)):
   - Skip when `p_is_reflection_probe`, `view_count != 1`, `!viewport.is_valid()`, or `!has_pending_depth_snapshot_request(viewport, frame_number)`.
   - Select resolved depth source (`RB_TEX_BACK_DEPTH` `R32_SFLOAT`, or depth-only `RD::TEXTURE_SLICE_DEPTH` shared view when `rb->get_depth_texture(0)` uses `D32_SFLOAT_S8_UINT` / `D24_UNORM_S8_UINT`), copy into `dst_gen->framebuffer_rid` via `copy_effects->copy_to_fb_rect(..., /*p_linear=*/false, ..., /*p_bilinear_filtering=*/false)` (`FILTER_NEAREST`), upload `256B` `SceneDepthSnapshotMeta256`, and commit `dst_gen`.
3. In `RenderSceneBuffersRD::cleanup()` ([render_scene_buffers_rd.cpp](../servers/rendering/renderer_rd/storage_rd/render_scene_buffers_rd.cpp:134)), call `invalidate_viewport_depth_snapshot` for the owning viewport so resized/closed viewports evict immediately.
4. **Success check**: Main-RD `[WaveGGodot]` Forward+ and Forward Mobile tests pass at both `MSAA_DISABLED` and **`VIEWPORT_MSAA_4X`**, confirming point-sampled silhouette sharpness, opaque-only Frame-0 capture on Mobile, exclusion of transparent draws, and `0` RD validation errors.
